# CMU 15-779 学习资料

这里预留个人学习资料的归档空间，目前还没有资料。后续可以保存 PDF 笔记、代码压缩包、实验数据和复现说明。

- 在本地仓库中将资料放在本目录或其子目录，通过 Git 提交并推送到 `main` 分支；部署后会自动出现在专题的「学习资料」列表中。
- 可以按自己的主题或日期建立子目录，例如 `notes/`、`code/`、`experiments/`。
- 请使用有含义的文件名。替换资料时可保持原文件名，以保留已有链接。
- 本目录内容会公开访问；提交前检查文件中是否包含密码、访问令牌或私人信息。
- 需要分享课程讲义时，可以在学习记录中链接 CMU 原站。

学习记录也通过本地 Git 维护：将 Markdown 放到 `content/posts/`，再提交并推送到 `main`。专题网页仅展示资料和记录。

`README.md`、隐藏文件和 `templates/` 目录不会进入资料索引。学习记录模板位于 `templates/learning-note.md`，完整维护说明见仓库的 `docs/cmu-15-779-maintenance.md`。
