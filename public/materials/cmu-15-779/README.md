# CMU 15-779 学习资料

这里归档 CMU 15-779 相关的中文学习译稿，保留译稿原始内容，便于个人学习时在线阅读或下载。

当前资料：

- `pytorch-paper-zh.md`：PyTorch 论文中文译稿
- `tensorflow-paper-zh.md`：TensorFlow 论文中文译稿
- `transformer-paper-zh.md`：Attention Is All You Need 中文译稿
- `flashattention-paper-zh.md`：FlashAttention 中文译稿
- `triton-paper-zh.md`：Triton 中文译稿
- `tvm-slides-zh.md`：TVM OSDI 2018 幻灯片中文译稿
- `cmu-15-779-translations.zip`：以上 6 份译稿的总压缩包

资料会自动显示在 [CMU 15-779 学习专题](https://liangqianxing.github.io/learning/cmu-15-779) 的「学习资料」列表中。

- 在本地仓库中将资料放在本目录或其子目录，通过 Git 提交并推送到 `main` 分支；部署后会自动出现在专题的「学习资料」列表中。
- 可以按自己的主题或日期建立子目录，例如 `notes/`、`code/`、`experiments/`。
- 请使用有含义的文件名。替换资料时可保持原文件名，以保留已有链接。
- 本目录内容会公开访问；提交前检查文件中是否包含密码、访问令牌或私人信息。
- 需要分享课程讲义时，可以在学习记录中链接 CMU 原站。

学习记录也通过本地 Git 维护：将 Markdown 放到 `content/posts/`，再提交并推送到 `main`。专题网页仅展示资料和记录。

`README.md`、隐藏文件和 `templates/` 目录不会进入资料索引。学习记录模板位于 `templates/learning-note.md`，完整维护说明见仓库的 `docs/cmu-15-779-maintenance.md`。
